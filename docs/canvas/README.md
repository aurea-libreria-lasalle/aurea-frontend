Imágenes de referencia de la guía de estilo y de las pantallas principales, en computadora y en celular. Ábrelas con cualquier visor de imágenes, en VS Code o en GitHub.

| Imagen | Pantalla |
| --- | --- |
| `01-guia-de-estilo.png` | Paleta, tipografía, botones, formularios, tarjeta de libro, estados de pedido y estados de pantalla |

| `03-detalle-libro.png` / `03-detalle-libro-celular.png` | Detalle de un libro |

Notas:

- Libros, precios y cifras son datos de ejemplo; en la app todo viene de la API.
- Es una referencia visual. Las clases CSS reales están en `docs/GUIA_CSS.md`; si algo no coincide, manda lo que diga el CSS (por ejemplo, en celular el catálogo muestra 2 columnas).
- Las pantallas que no aparecen (checkout, mis pedidos, direcciones, login) usan los mismos componentes de la guía de estilo.
